
# Code of Conduct

## Our Ambition:

The ambition for Thermitage, sharing an initial collection of datasets generated specifically for IRT-3DDF, is to provide a collaborative repository to advance photogrammetric data fusion methods focussed on the significance of historic buildings.

Our hope is that researchers will be able to access and exchnage datasets for the continued development of new methods and the expansion of learning-based appraoches for IRT-3DDF.

## Contributing Data:
If you would like to upload or contribute a dataset to this repository, please contact **Neil Sutherland** (sutherland.neil@gmail.com) before submitting, so coordination of licensing, size, and metadata consistency can be undertaken.

## Questions & Queries:
For any additional details regarding datasets, clarification, or greater access, please reach out directly to **Neil Sutherland** (sutherland.neil@gmail.com).
